## Spacing

- Recommended scale:
  - 2, 4, 6, 8, 10, 12, 14, 16, 20, 24, 40, 56, 80
- Gap values used:
  - 2, 4, 6, 8, 10, 16, 20, 24, 40, 56, 80
- Padding numeric values used:
  - 12, 14, 16, 20, 24
- Padding array patterns used:
  - `[0,2]`
  - `[10,16]`
  - `[16,8]`
  - `[16,13]`
  - `[17,16]`
  - `[44,0,0,0]`
